# oh-my-bookmarks

A handy bookmark toolkit for coder.

## Development

```bash
pnpm install
pnpm dev
```

Load the extension from `.output/chrome-mv3/` in Chrome's extension page.

## Testing

```bash
pnpm test         # Unit tests
pnpm test:e2e    # E2E tests
```

## Build

```bash
pnpm build       # Chrome
pnpm build:firefox
pnpm zip         # Pack for store
```
